# Changelog

## 1.2.0

### Minor Changes

- 6cc501a: В данные визита добавлено отображаемое название приложения с учётом его локализации. Обновление не требует изменений интеграции.
- 2e76edb: Удалены сигналы статуса Bluetooth и App Tracking Transparency.

## 1.1.0

### Minor Changes

- f8f80eb: Объединены одновременные get() с одинаковыми настройками между экземплярами SDK: один сбор, HTTP-запрос и сохранение результата, с независимой отменой ожидающих.

  Сбор ограничен пятью секундами. Готовые сигналы сохраняются, незавершённые передаются как null/error; бюджет HTTP начинается после сбора. Публичные сигнатуры и каталог iOS не изменены.

- 787b8d6: Добавлены тип и версия отправляющего SDK в запрос регистрации визита.
  Для React и Vue передаются метаданные обёртки.

## 1.0.0

- Первая бинарная поставка FingprintAgent для iOS через Swift Package Manager.
